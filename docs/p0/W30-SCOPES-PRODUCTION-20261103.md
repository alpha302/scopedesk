# W30：范围列表批量读取计划

2026-11-03（Asia/Shanghai），分支 `batch-p0-p1`。按用户授权将影响常用页面的独立读路径项提前交付；没有把 P2/P3/P4/P5 全批次或 P0 退出标为完成。

## 改动

`store.go` 原先先读授权范围，再对每范围调用一次 `plan()`，N 个范围为 N+1 次 SQL。现在仍使用原范围/项目/角色过滤和资产计数 SQL，随后只对已返回范围 ID 一次批量读取 `monitor_plans`。

0 范围为 1 次 SQL；非空范围为固定 2 次 SQL。不改变范围顺序、项目策略、资产计数、计划字段、缺计划时的原默认值（未启用、24 小时、crtsh+CertSpotter、原 collection_mode 空值等）。计划逐范围独立赋值，不通过 JOIN 扩大或重复范围；批量查询只接收已筛选 ID。单项 `plan()` 接口保留，其缺省值与批量路径共用 `defaultMonitorPlan()`。

没有新增缓存，没有改变监控执行/调度、授权复核、速率或请求预算。资产 count 相关子查询仍保留，不能称为资产列表/概览已优化。未新增索引或迁移，写入路径未改。

文件：`store.go`；新增 `w30_scopes_test.go`、`.github/workflows/w30-scopes.yml`、`deploy/deploy_w30_20261103.py`。
