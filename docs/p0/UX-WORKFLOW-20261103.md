# ScopeDesk 目标流程优化

2026-11-03，Asia/Shanghai。本批实现用户七页面评审中剩余的使用逻辑优化，连同第一批状态修正一起验收发布。发布结果以本文末尾的实际记录为准；不以本次 UI 改造关闭其他未验收的 W 项。

## 已实现

- 导航归并为概览、资产、目标、发现、设置五项。资产列表和变更事件使用同级标签；项目与权限、账户、插件、邮件、规则等原有功能完整保留在设置内，管理员入口仍受角色限制。
- 目标详情集中展示规则、数据源、计划、运行历史。查看资产和变化自动带入当前目标。运行历史和事件在数据库查询阶段按目标及权限筛选，再应用条数限制，避免先取全局 100 条导致目标历史消失。
- 新增目标默认只展示域名、包含子域及保存时的一次授权确认。支持每行一个、最多 50 个域名；复用既有单域名 API，逐个报告结果。部分失败时保留失败项，已成功项不自动重试。批量输入共用本次明确选择的授权和排除规则。
- 排除项、精确粒度、速率、并发、请求上限、时间窗和 HTTP 许可放进高级设置。保守、标准、积极预设仅在用户选择时应用，速率受项目上限约束。编辑已有目标保留原值；显示“本目标默认值 / 项目合计上限”，无额外任务级输入。
- 每目标仅一组数据源和发现后的处理方式，存入既有计划配置，即使不启用定时计划也可以保存。手动执行发送 `use_saved_config:true`，服务端读取同一份配置；禁止同请求覆盖来源或模式。未保存修改时不能执行，停用旧不兼容计划仍可保留原设置。
- 资产页保留搜索、目标、工作状态、网络分类四项基础筛选；更多筛选折叠。保存视图按账户和项目存储在当前浏览器，最多 20 个，不跨设备同步。域名列不拆行，IP 默认显示两个，剩余通过 `+N` 展开。
- 单工作空间隐藏名称层级，单项目隐藏全局项目切换；工作空间管理保留为可展开区域，创建表单按需打开。
- 企业探索的规模和预算参数放进高级。确认归属后直接带入目标创建，已确认候选可“转为目标”。域名和项目无需重填，保存时仍明确确认授权；沿用已有导入接口的权限、黑名单、事务和幂等检查，首次仅创建精确目标，关闭 HTTP 和计划，不自动执行。
- 概览三步清单：添加目标、首次执行、查看结果；前两项使用可见实际记录，结果查看进度按账户/项目保存在当前浏览器。
- 第一批 HTTP 许可与实测分离、部分成功/失败语义、不兼容来源置灰和服务端拒绝、重复异常折叠、事件中文摘要继续保留。旧事件不追认为真实 HTTP 下线，原始证据仍可展开。

## 验证

- Node 加载实际 `web/app.js`，23 项行为验收，覆盖共享配置、未保存禁止执行、授权不扩大、计划停用、批量失败重试、企业带入、权限导航与目标历史分组。
- Linux 实际构建生产二进制与测试二进制；独立临时 PostgreSQL 16 验收，不使用生产数据库、不启动采集 worker/scheduler。
- 增加真实 API 验收：不兼容来源不创建作业；手动读取已保存的来源与模式；目标历史过滤发生在 LIMIT 之前；无权限/无效目标不扩展查询；企业候选双重确认、权限、幂等、精确范围及不自动执行。
- 浏览器使用本地合成数据，核对五入口、基础/高级表单、资产四筛选、IP 展开、视图保存后刷新、企业带入、设置和目标历史。390px 窄屏菜单无重复、页面无水平溢出。浏览器截图不是生产资产数据。
- 首次临时 PG 测试因测试样例缺少 `asset_events.dedupe_key` 失败；已补齐样例后重跑，原始失败日志保留。未为此修改事件数据合同。
- 企业真实 API 新验收发现原导入接口遗漏 `scopes.policy` 必填字段，导致创建失败。接口现在明确保存空备注，保留精确范围、权限、幂等与关闭探测/计划的行为；修复前日志保存为 `enterprise-red.log`。
- GitHub Actions 使用临时 PG16 与 race detection，按准确提交验收后才允许线上切换。实际 CI 和部署证据在 `evidence/ux-workflow-20261103/`。

## 发布约束

无数据库迁移，版本保持 18。保留所有现有授权、数据源账户/预算、插件配置、计划、历史资产与事件。生产切换前核对旧源码及运行文件摘要，确认无进行中的作业，保存源码/配置/状态和数据库备份；切换失败恢复旧二进制与源码，不覆盖用户数据库。

本批是使用逻辑优化，不新增企业商业数据源适配器、全端口扫描或“全量资产覆盖”保证；这些能力继续按现有实际状态展示。
